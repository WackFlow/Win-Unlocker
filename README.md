# Win-Unlocker

Автоматизированный Bash-скрипт для быстрого сброса паролей и управления учетными записями Windows (`SAM`) прямо из LiveCD Ubuntu с помощью утилиты `chntpw`. Скрипт берет на себя всю рутину по поиску, исправлению ошибок файловой системы и монтированию разделов.

## 🚀 Быстрый старт

Загрузитесь в Ubuntu (LiveCD), откройте терминал и выполните одну команду:

```bash
sudo bash -c "$(wget -qO- https://raw.githubusercontent.com/WackFlow/Win-Unlocker/refs/heads/main/admin.sh)"
```

## ✨ Основные возможности

* **Полный автопоиск системного раздела:** Скрипт самостоятельно сканирует все доступные NTFS-разделы, монтирует их только для чтения (`-o ro,force`, чтобы находить даже системы в режиме гибернации / fast startup) и ищет директорию конфигурации `Windows/System32/config`.
* **Автоматическая установка зависимостей:** Сам обновляет пакетную базу и ставит необходимые для работы утилиты `chntpw` и `ntfs-3g`.
* **Обход проблем с гибернацией:** Принудительно сбрасывает dirty-флаг через `ntfsfix` **только для выбранного целевого раздела** — соседние диски не трогаются.
* **Удобный интерактивный режим:** После подготовки запускается меню `chntpw`, где можно сбросить пароль, активировать учетную запись или выдать права администратора любому пользователю.
* **Безопасное завершение:** Синхронизирует изменения, размонтирует диск и предлагает перезагрузить ПК.

## 🛠️ Указание раздела вручную

Если автоматический поиск вам не подходит, вы можете передать точный путь к разделу (например, `/dev/nvme0n1p3`) в качестве аргумента.

```bash
sudo bash -c "$(wget -qO- https://raw.githubusercontent.com/WackFlow/Win-Unlocker/refs/heads/main/admin.sh)" -- /dev/nvme0n1p3
```

### Когда это полезно?

1. **Несколько NTFS-дисков:** У вас установлено несколько систем Windows или присутствует recovery-раздел, в котором автопоиск может случайно обнаружить дубликат папки конфигурации.
2. **Сбой проверки файловой системы:** Раздел помечен как поврежденный ("грязный") и не монтируется в режиме read-only для первичной проверки, но вы точно уверены, какая именно из систем вам нужна.

## ⚠️ Поведение при ошибках

Если скрипт не сможет обнаружить ни одного подходящего NTFS-раздела с установленной операционной системой, он не станет совершать слепых действий. Программа выведет на экран полный список доступных накопителей (`lsblk -f`) и завершит работу с ошибкой.

### Что делать в этом случае

1. **Проверьте список разделов** в выводе `lsblk -f`. Ищите строки с `FSTYPE=ntfs`.
2. **Запустите скрипт с явным указанием раздела** — тем, который считаете системным. Пример команды — в разделе «Указание раздела вручную» выше.
3. **Если раздел повреждён** и не монтируется даже read-only, можно вручную примонтировать его с `-o remove_hiberfile,force` и запустить chntpw напрямую:

```bash
sudo mkdir -p /mnt/win
sudo mount -t ntfs-3g -o remove_hiberfile,force /dev/nvme0n1p3 /mnt/win
sudo chntpw -i /mnt/win/Windows/System32/config/SAM
```
